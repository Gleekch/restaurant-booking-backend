# Manrope

Variable font by Mikhail Sharanda / The Manrope Project Authors.
Bundled locally for the desktop and staff web interfaces; no font CDN is used.

- Original file: `ofl/manrope/Manrope[wght].ttf`

- Local filename: `Manrope-Variable.ttf` (unmodified font binary).
